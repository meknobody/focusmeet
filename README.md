# FocusFlow — Timetable & Pomodoro Task Hub

A modern, standalone productivity app that combines a **Pomodoro Focus Timer**, **Task Manager**, and **Weekly Timetable Schedule** into a single cohesive dashboard.

## 🚀 Key Features

* **⏱️ Pomodoro Focus Station:**
  * Configurable intervals: Pomodoro (25m), Short Break (5m), Long Break (15m).
  * SVG circular progress ring with real-time digital countdown.
  * Direct task attachment: assign any task from your list to track completed pomodoros.
  * Built-in Web Audio chime alert when time expires (zero external dependencies).

* **📋 Prioritized Task Checklist:**
  * Categorization: Study, Work, Personal, Health.
  * Priority tags: High 🔥, Medium ⚡, Low 🌿.
  * Pomodoro block estimation (e.g., 🍅 1/3 completed).
  * Quick-add input bar and filter chips.

* **📅 Daily & Weekly Timetable:**
  * 7-day schedule grid with automatic current-day detection.
  * Add custom time slots for classes, lectures, routines, and deep work blocks.
  * Visual color badges for different activity categories.

* **💾 Persistence & Customization:**
  * Saved automatically in your browser's `localStorage`.
  * Customizable timer durations & notification toggles.
  * Pre-populated with starter sample data.
